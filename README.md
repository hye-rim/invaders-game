# 스페이스 인베이더 👾

추억의 오락실 스페이스 인베이더(Taito, 1978)를 본뜬 혼자 하는 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작(PC): **← →** 이동, **스페이스** 발사, `P` 일시정지, `M` 소리.
- 조작(폰): 왼쪽 ◀ ▶ 이동, 오른쪽 빨간 버튼 발사.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 외계인 **55마리**(11열 × 5줄)가 **한 마리씩 차례로** 움직입니다(1/60초에 한 마리). 줄어들수록 한 바퀴 도는 시간이 짧아져 빨라집니다. 벽에 닿으면 8픽셀 내려오고 방향을 바꿉니다. 하나라도 대포 높이까지 내려오면 남은 목숨과 상관없이 끝입니다.
- 점수: 맨 위 줄 30, 가운데 두 줄 20, 아래 두 줄 10. 내 총알은 **한 번에 한 발**입니다.
- 외계인 총알은 최대 3발(굴러가는 총알은 내 위치를 노림). 내 총알과 부딪히면 둘 다 사라집니다.
- **방어벽** 4개는 도트 단위로 깎입니다(외계인 총알·내 총알·지나가는 외계인 모두). 판이 바뀌면 새로 생깁니다.
- **UFO**: 25.6초마다 위를 지나가고(외계인이 8마리 이상일 때), 점수는 내가 쏜 횟수로 정해집니다(23번째 발에 300점).
- 3대로 시작하고 1500점에 한 대 늘어납니다. 판을 깨면 더 낮은 줄에서 시작하는 다음 판(여덟 번 낮아지고 처음으로 돌아감).

## 참고한 것과 확인하지 못한 값
- 공개 자료([Wikipedia](https://en.wikipedia.org/wiki/Space_Invaders), [arcade-history](https://www.arcade-history.com/?amp=&id=2537&page=detail), [MobyGames](https://www.mobygames.com/game/8806/space-invaders/) 요약)에서 확인: 55마리·11×5, 외계인 점수 30/20/10, 줄어들수록 빨라짐, UFO 50~300점, 방어벽 4개가 깎임, 목숨 3.
- 기억에 의존했거나 자료를 찾지 못한 값: UFO 가 쏜 횟수로 점수가 정해지는 표(23번째 발 300점은 널리 알려진 설명, 나머지 칸의 값은 확인하지 못함), 1500점 추가 대포(원작의 설정 스위치 값으로 알고 있음), UFO 간격 25.6초, 외계인 총알 세 종류의 모양과 속도·발사 간격, 한 번에 2픽셀씩 움직이는 것과 8픽셀 내려오는 것, 판마다 시작 높이 표, 방어벽 모양, 대포 속도와 총알 속도.
- 그림은 원작과 비슷한 도트로 직접 그렸고, 소리는 합성한 것입니다(행진 소리 4음).

## 난이도 (쉬움 · 보통)
- **보통**은 고전 규칙 그대로(목숨 3개, 외계인 총알 3발, 외계인 이동 속도 100%, 총알 초당 96픽셀). **쉬움**은 목숨 5개, 외계인 이동 속도 75%, 외계인 총알 초당 78픽셀, 동시에 2발까지.
- 처음 화면과 게임 오버 화면에서 고른다(`invadersLevel`). **최고 기록은 난이도마다 따로** 저장한다(보통 `invadersBest`, 쉬움 `invadersBestEasy`). 로비의 최고 기록은 보통 기록이다.
- 고른 근거: 사람 흉내 봇(0.1~0.4초 반응, 움직임 예측, 총알 피하기)으로 재면 보통은 서툰 봇 1판·보통 봇 2판·능숙 봇 4판, 쉬움은 1판·3판·7판까지 간다.
